First release: resolves GW2 chat links (items with stats and rune / sigil bonuses, skins, skills incl. mount / transform skills and effects, traits, recipes) into names, icons and tooltips for the Trailpack addons, in English and German. Built-in waypoints, build links and event timers that work offline; disk cache, rate-limited requests to the official GW2 API, "Offline only" mode and an options page.
