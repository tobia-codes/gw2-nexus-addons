# Changelog — Trailpack Core

All notable changes for players. New entries go under `## Unreleased`; `tools/release.py`
turns that section into the released version.

## Unreleased

### Added
- First version: resolves GW2 chat links (items with stats and rune / sigil bonuses, skins,
  skills incl. mount / transform skills and effects, traits, recipes) into names, icons and
  tooltips for other addons, in English and German.
- Built-in data that works offline: waypoints and points of interest with their map, build links
  (elite specialisation), event timers (world bosses, metas, ...).
- Disk cache, bundled and rate-limited requests to the official GW2 API, "Offline only" mode.
- Options page: status, language, game build, cache size and "Clear cache".
