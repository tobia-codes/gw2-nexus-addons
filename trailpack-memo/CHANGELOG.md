# Changelog — Trailpack Memo

All notable changes for players. New entries go under `## Unreleased`; `tools/release.py`

### Added
- First release: notes with markdown, checklists, groups, daily / weekly notes, themes,
  backup and export / import, English and German.
- Chat-link chips with names, icons and tooltips, and event timer chips with live countdowns
  (`/e` suggestions, Event button) — extended features with the Trailpack Core addon; without it
  they are greyed out.
- Left-click a waypoint chip to copy its code.
